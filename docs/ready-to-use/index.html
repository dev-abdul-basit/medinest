Order of operations

  1. Play Store first. Run as a Store Listing Experiment (v1 vs current). Don't push to 100 % directly.
  2. LinkedIn second. Profile + pinned post the same day. LinkedIn is slow; start the clock.
  3. X third. Pinned thread + 5 daily replies from Day 1.
  4. Reddit last. Phase 1 = listen for 2 weeks. Don't post. Don't comment. Just read.

Daily time budget (after setup)

  • X replies: 30 min/day (5–10 replies)
  • LinkedIn comments: 15 min/day (5 comments)
  • Reddit reading then commenting: 30–45 min/day
  • Original posts: per file's schedule

Total: ~1.5 hr/day. Compounds over 90 days.
